# Keystead common-password deny list.
#
# Lines beginning with # are comments. Comparison is case-insensitive and happens after the
# candidate has been lower-cased, so entries here are written in lower case.
#
# This list is deliberately weighted towards passwords that are TWELVE CHARACTERS OR MORE,
# because the length floor already rejects the classic top-1000 (almost all of which are
# shorter). A deny list full of "123456" and "password" would look thorough while blocking
# nothing the length rule had not already blocked.
#
# It is a backstop, not a substitute for a breach corpus. An installation that wants real
# coverage should implement IPasswordPolicy against a k-anonymity lookup; the interface is
# shaped to allow that without touching anything else.
